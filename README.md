# Fantasy Basketball Weekly Reports

A small non-commercial project for generating visual weekly reports and statistical summaries for Yahoo Fantasy Basketball leagues.

The application will use read-only Yahoo Fantasy Sports API access to retrieve league data such as matchups, standings, scoring categories, team statistics, rosters, and transactions.

The goal is to generate easy-to-share visual weekly reports for participants of fantasy basketball leagues in which I participate.

The project is currently in early development.
